# 项目概述

适用于产品一部 AOM/RPA/RPOM UI2.0 的组件库.

本项目包含两个 npm 包, 一个是 KSW组件库(vue3), 另一个是 KSW图标库.

---

<br />

## KSW组件库(vue3)

<br />

### 兼容性

> Chrome : 80+
>
> Firefox : 74+
>
> Safari : 13.1+
>
> Edge : 80+

<br />

### 版本

目前还处于快速开发迭代中。

<br />

### 使用方式:

<br />

#### 安装:

```bash

# npm
npm install @ksware/ksw-ux --save

# yarn
yarn add @ksware/ksw-ux

# pnpm
pnpm add @ksware/ksw-ux

```

#### 全局引入:

```bash
# main.js/ts
import KSWUX from '@ksware/ksw-ux';

const app = createApp(App)
app.use(KSWUX)
app.mount('#app')

```

ps: 组件库自带 KSW图标库, 无需重复安装。

---

<br />

## KSW图标库

```bash
# npm
npm install ksw-vue-icon

# yarn
yarn add ksw-vue-icon

# pnpm
pnpm add ksw-vue-icon

```

### 全局引入

```bash
# main.js/ts
import { KswIcon} from 'ksw-vue-icon'
# 包含图标的动画样式
import 'ksw-vue-icon/styles/icon.css';

const app = createApp(App)
app.use(KswIcon)
app.mount('#app')



```

### 按需引入:

```bash
# 引用
import { IconName } from 'ksw-vue-icon'

```

### 使用方式

```bash

# 使用
<IconName :size="24" color="#333" />

```

[图标库预览地址](https://sengoku-f.github.io/KSW-vue-icon/), 可以在这里查看所有图标的效果, 点击图标, 复制到粘贴板。

更多使用方式请参考 [KSW-设计文档库](https://ksw.design.donxj.com/components/icon)。
